01 - Emmet

Plugin para escribir HTML y CSS mas rapido

01 - Child >

Crea elementos hijos dentro de otros elementos.

Ejemplo:

ul>li>a =>

Resultado:

<ul>
    <li>
        <a href=""></a>
    </li>
</ul>

02 - Sibling +

Crea elementos hermanos al mismo nivel.

Ejemplo:

header+section+footer =>

Resultado:

<header></header>
<section></section>
<footer></footer>

03 - Multiplication *

Repite elementos varias veces.

Ejemplo:

ul>li*3 =>

Resultado:

<ul>
    <li></li>
    <li></li>
    <li></li>
</ul>

04 - Class .

Crea el atributo class.

Ejemplos:

div.important =>

.danger =>

Resultados:

<div class="important"></div>
<div class="danger"></div>

05 - Classes ...

Crea varias clases en un mismo elemento.

Ejemplo:

div.red.green.blue =>

Resultado:

<div class="red green blue"></div>

06 - Identification #

Crea el atributo id.

Ejemplo:

menu#cod123 =>

Resultado:

<menu id="cod123"></menu>

07 - Text {}

Inserta contenido de texto.

Ejemplos:

p{lorem ipsum dolor} =>

a{Click Here} =>

Resultados:

<p>lorem ipsum dolor</p>
<a href="">Click Here</a>

08 - Custom Attributes []

Crea atributos personalizados o especificos.

Ejemplo:

input[type=number] =>

Resultado:

<input type="number">

09 - Item Numbering $

Agrega numeros consecutivos.

Ejemplo:

ul>li.option$$*3 =>

Resultado:

<ul>
    <li class="option01"></li>
    <li class="option02"></li>
    <li class="option03"></li>
</ul>

10 - Reverse Numbering @-

Invierte el orden de numeracion.

Ejemplo:

ul>li.option$$@-*3 =>

Resultado:

<ul>
    <li class="option03"></li>
    <li class="option02"></li>
    <li class="option01"></li>
</ul>

11 - Base Numbering @N

Define un numero base para una secuencia.

Ejemplo:

ul>li.option$$@5*3 =>

Resultado:

<ul>
    <li class="option05"></li>
    <li class="option06"></li>
    <li class="option07"></li>
</ul>

12 - Climb Up ^

Sube un nivel en la estructura.

Ejemplo:

div>ul>li^span =>

Resultado:

<div>
    <ul>
        <li></li>
    </ul>
    <span></span>
</div>

13 - Grouping ()

Agrupa elementos para controlar la estructura.

Ejemplo:

(header>h1)+(section>p) =>

Resultado:

<header>
    <h1></h1>
</header>
<section>
    <p></p>
</section>

14 - Lorem lorem

Genera texto de relleno.

Ejemplos:

p>lorem =>

p>lorem5 =>

Resultados:

<p>Lorem ipsum dolor sit amet, consectetur adipiscing elit.</p>
<p>Lorem ipsum dolor sit amet.</p>

15 - HTML Documents !

Crea estructuras base de documentos HTML.

Ejemplos:

!

html:5

html:4t

html:xt

Resultado:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

16 - Meta Tags meta

Genera etiquetas meta frecuentes.

Ejemplos:

meta:vp =>

meta:compat =>

Resultados:

<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta http-equiv="X-UA-Compatible" content="IE=edge">
