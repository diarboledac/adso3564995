01-Emmet

Plugin for faster HTML and CSS coding

01-Child >

Creates child elements (nesting). Crea elementos hijos (anidación).

Example

ul>li>a ↔️

Result

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling +

Creates sibling elements. Crea elementos hermanos.

Example

header+section+footer ↔️

Result

<header></header> <section></section> <footer></footer>

03-Multiplication *

Repeats elements multiple times. Repite elementos varias veces.

Example

ul>li*5 ↔️

Result

<ul> <li></li> <li></li> <li></li> <li></li> <li></li> </ul>

04-Class .

Creates a class attribute. Crea un atributo de clase.

Example

div.important ↔️

.danger ↔️

Result

<div class="important"></div> <div class="danger"></div>

05-Classes ...

Creates multiple class attributes. Crea múltiples atributos de clase.

Example

div.red.green.blue ↔️

Result

<div class="red green blue"></div>

06-Id #

Creates an ID attribute. Crea un atributo de ID.

Example

div#header ↔️

Result

<div id="header"></div>

07-Text { }

Inserts text content. Inserta contenido de texto.

Example

p{Hello World} ↔️

Result

<p>Hello World</p>

08-Custom Attribute [ ]

Creates custom attributes. Crea atributos personalizados.

Example

input[type=text name=username] ↔️

Result

<input type="text" name="username">

09-Item Numbering $

Adds consecutive numbers. Añade números consecutivos.

Example

ul>li.item$*5 ↔️

Result

<ul> <li class="item1"></li> <li class="item2"></li> <li class="item3"></li> <li class="item4"></li> <li class="item5"></li> </ul>

10-Reverse Numbering @-

Inverts numbering order. Invierte el orden de numeración.

Example

li.item$@-*5 ↔️

Result

<li class="item5"></li> <li class="item4"></li> <li class="item3"></li> <li class="item2"></li> <li class="item1"></li>

11-Base Numbering $@N

Defines a base number for sequences. Define un número base para secuencias.

Example

li.item$@3*5 ↔️

Result

<li class="item3"></li> <li class="item4"></li> <li class="item5"></li> <li class="item6"></li> <li class="item7"></li>

12-Climb Up ^

Moves up one level. Sube un nivel.

Example

div>p^span ↔️

Result

<div> <p></p> </div> <span></span>

13-Grouping ( )

Groups elements together. Agrupa elementos juntos.

Example

div>(header>nav)+section+footer ↔️

Result

<div> <header> <nav></nav> </header> <section></section> <footer></footer> </div>

14-Lorem lorem

Generates placeholder text. Genera texto de relleno.

Example

lorem10 ↔️

Result

Lorem ipsum dolor sit amet, consectetur adipisicing elit. Quisquam, necessitatibus.

15-HTML Documents !

Creates various HTML document types. Crea varios tipos de documentos HTML.

Example

! ↔️

Result

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Document</title> </head> <body> </body> </html>

16-Meta Tags meta:vp

Generates meta tags. Genera etiquetas meta.

Example

meta:vp ↔️

Result

<meta name="viewport" content="width=device-width, initial-scale=1.0">
